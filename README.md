# Agile-Team-Standup-Tracker
Support software teams with an AI-powered asynchronous standup system.


This project is an AI-powered asynchronous standup tracker designed to support agile software teams. Team members submit daily updates, which are stored by sprint and date in persistent memory. A Summary Agent generates a concise team-wide update, a Blocker Detector Agent identifies risks or unresolved issues, and a Sprint Progress Estimator Agent analyzes overall sprint health and delivery confidence. These agents work together to convert individual standup notes into useful daily and weekly digests that teams can review or export for communication and tracking.
